# Cheat sheet

The keys used most, with the Modern keymap (the default). Help > Keyboard reference
(F1) lists every key as your keymap has it.

| Keys | What they do |
|---|---|
| F10, Alt-letter | Menus |
| Ctrl-P | Command palette: every command by name |
| Alt-G | Go to file; `@` symbols, `#` project symbols, `:` line |
| F2 / F3 | Save / open |
| Ctrl-W, Alt-F3 | Close the window |
| F6, Alt-1..9 | Next window, window by number |
| Ctrl-E | File explorer |
| Ctrl-F / Ctrl-R / Ctrl-L | Find / replace / again |
| Shift-F3 | Find in files |
| Ctrl-G | Go to line |
| Ctrl-D | Duplicate line |
| Alt-- / Alt-= | Fold or unfold the block / expand all |
| Ctrl-Z / Ctrl-Y | Undo / redo |
| F7 | Language server on / off |
| F12, Shift-F12 | Go to definition, find references |
| Alt-I | Describe the symbol at the cursor |
| F9 / Ctrl-F9 | Build / run |
| Ctrl-Enter / Ctrl-Shift-Enter | Run # %% notebook cell / run cell and advance |
| Shift-F5 | Debug; continue |
| Ctrl-F8 | Toggle a breakpoint |
| F7 / F8 / Shift-F8 | (debugging) step in / over / out |
| Alt-F11 | Terminal |
| Ctrl-F10 | Send the selection to the Mojo REPL |
| Alt-N / Alt-B | Next / previous changed block (git) |
| Ctrl-F11 / Shift-F11 | Agent panel / mention selection in prompt |
| Shift-F10 | Notifications and what is running |
| F1 / Ctrl-F1 | Explain error or keys / docs of name at cursor |
| Shift-F1 / Alt-F1 | Mojo documentation reader / search all docs |

In the **documentation reader** (Shift-F1): **/** searches all books, **Ctrl-F** (**F3** /
**Shift-F3**) searches on the page, **G** jumps to a heading on the page, **C** copies a
code block, **T** opens it in a scratch buffer, and **O** opens your own practice copy.
In the **agent panel** (Ctrl-F11): **Alt-M** cycles mode (`ask` / `accept-edits` /
`auto`), **Alt-O** picks the model, **Alt-T** sets thinking, **Tab** completes `@file`,
and **Alt-Up** / **Alt-Down** recall prompts.
